# COMP 584 - Project 3: CSS Grid

Live site: https://eli-cub.github.io/comp584-project3/

GitHub: https://github.com/eli-cub/comp584-project3

This is my Project 2 hockey website remade with CSS Grid instead of Flexbox. I kept the same teams, colors, and content.

I used `display: grid`, `grid-template-columns`, `grid-template-rows`, `gap`, `grid-column`, and `grid-row` from the Week 6 lecture. The cards change from one column on mobile to two on tablets and four on desktops. I also used grid line numbers to make some cards wider and to change the order of the Detroit, Chicago, and Boston cards on tablets.

Two extra Grid properties I added are `grid-auto-rows` and `grid-auto-flow`. Their comments in `style.css` explain what they do.
